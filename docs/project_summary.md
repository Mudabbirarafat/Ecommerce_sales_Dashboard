# Project Summary (For Resume & Interview)

## Project Name
E-commerce Sales Analytics Dashboard

## Problem Statement
Business wants to monitor sales performance and profitability across regions, products, and customer segments. The dashboard should support quick decision making.

## What I Built
- Clean dataset with 5 tables (orders, order_items, products, customers, returns)
- SQL queries for KPIs and analysis
- Power BI dashboard with DAX measures
- Insights & recommendations

## Key Insights (Example)
1. Technology category contributes the highest revenue and profit.
2. Same Day shipping has higher AOV but also slightly higher return rate.
3. A small set of products drive a significant portion of sales (Pareto).
4. Certain states show high sales but low profit margin → discount/cost issue.

## Resume Bullets (Copy-Paste)
- Built an interactive **E-commerce Sales Analytics Dashboard** using **Power BI**, analyzing 5K+ orders across products, regions, and customer segments.
- Wrote **SQL queries** to compute KPIs (Revenue, Profit, Profit Margin %, AOV, Return Rate) and generate monthly trend reports.
- Designed DAX measures and slicers for dynamic filtering by **date, region, category, and segment**, enabling business-ready insights.
